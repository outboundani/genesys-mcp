# makeittalk brand kit

## The name

**makeittalk** - always lowercase, always one word, written with the trailing
period in display contexts: **makeittalk.** The period is the brand's full
stop: paste a link, done. The domain is the name: makeittalk.dev.

Never: MakeItTalk, Make It Talk, MIT (reserved by a certain university).
Short form in tight spaces: **mit_** (the key prefix) as a wink, never as the
public name.

## The idea

Every API can already listen. makeittalk gives it a voice. The product turns
software nobody's AI can use into software every AI can use, and it does it
from the same artifact humans use: the docs.

One-liner: **paste a link. get an MCP.**

## Logo

`logo.svg` - a speech bubble carrying a soundwave (three bars). The bubble is
software talking; the bars are the voice. Use the mark alone at small sizes
(favicon), the full lockup elsewhere. Clear space: one bar-width around the
mark. Don't recolor the bars to anything but paper-green on ink, or
deep-green on paper.

## Color

Mostly light pale green. Black does the talking.

| Token | Hex | Use |
|---|---|---|
| paper | `#E9F4EA` | page background - the brand color |
| paper-2 | `#DEEEE1` | alternating section wash |
| card | `#F7FBF7` | cards, inputs |
| ink | `#0C120D` | text, primary buttons, the terminal, the logo |
| deep green | `#1C6B3C` | the one accent: links, highlights, the wordmark period |
| soft green | `#D3ECD9` | badges, code chips |
| line | `#C2DCC8` | borders |
| muted | `#46564A` | secondary text |
| terminal green | `#A8D9B4` on `#0F1611` | generation logs, code |

Dark mode inverts to green-on-near-black (`#DFF0E2` on `#0B120C`, accent
`#7FD49A`) - the same palette his portfolio calls "green-and-black mode."

Rules: one accent (deep green) used identically everywhere. No purple, no
gradients-for-gradients. Buttons are ink-black with pale green text.

## Type

- **Display:** Space Grotesk (500/600/700), tight letter-spacing (-0.025em),
  lowercase headlines.
- **Body:** system-ui stack.
- **Mono:** ui-monospace (SF Mono/Menlo/Consolas) - endpoints, keys, logs,
  eyebrows. The mono voice is the product speaking; use it whenever the
  machine is talking.

## Voice

Lowercase confidence. Short sentences. Concrete over clever, but clever is
allowed one moment per page. Say what the thing does; never say elevate,
seamless, unleash, revolutionize. No em-dashes; commas and periods carry the
rhythm. Numbers are real or absent.

Taglines on rotation:
- paste a link. get an MCP.
- give your API a voice.
- your software, speaking fluent AI.
- it builds, not just reads. (inherited from the genesys-mcp lineage)

## Provenance line

Where there's room: "from the builder of genesys-mcp and five9-mcp." The
open-source lineage is the trust story; link it, don't paraphrase it.
